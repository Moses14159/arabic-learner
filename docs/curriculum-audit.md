# Qalam 课程与学习有效性审计

审计日期：2026-11-16。对象：当前仓库中的课程数据、字母模块、词法模块和实际练习流程。以下区分代码事实、教学判断和待验证方案。本报告没有真实用户留存或前后测数据，因此不把界面优化等同于学习效果或留存已经提高。

> 范围更新：用户随后明确第二路线仅需 Tajweed，不建设经典精读或释义。下文保留初始课程审计，当前实现见 `project-review.md` 与 `tajweed-scope.md`。

## 判断

**现有内容适合作为中文使用者学习现代标准阿语的入门讲义和语法练习工具；还不足以充当能独立带领零基础用户掌握听说读写的完整课程。**

优势在于：字母形态、动符、词根、变位和逐词语法解析放在同一产品里；中文解释降低了入门门槛；初级名词句到介词、所属、代词、动词句的主线大致连贯。这些资产值得保留。

主要缺口是：内容以“讲过哪些语法”为组织中心，缺少“用户能完成什么任务”的验收标准；困难专题练习量反而减少；看提示完成固定句子和长期独立掌握没有区分。对想系统理解语法的人较有吸引力；对主要想旅行交流或轻松入门的人，认知负担偏高，第一周获得实用表达的速度偏慢。

## 当前顺序：合理之处与应调整部分

1. **保留第 1–5 课的基础链。** 指示与名词句 → 定指与形容词 → 介词 → 所属 → 物主，是可以复用同一小组词汇逐步增加结构的链条。
2. **导引 3 过早承担正式词法教学。** 尚未稳定认字，便要求理解三母词根、主动名词、时空名词、第二式分词。可保留“书、写、作者是一家人”的一分钟发现活动，把术语和派生规则移到有约几十个熟词之后。这是教学设计判断，不是说初学者不能接触词根。
3. **字母学习与主课还没有形成明确先修闭环。** 字母分组课和辨形测验是独立入口；完成主课不要求能读出所用字母。建议以每课出现的少数字母和词为单位，交替进行字形、声音、简单表达，避免先背完所有字母才开始交流，也避免未经铺垫直接拼整句。
4. **导引 2 的实用问候方向正确，但第 8 课又以语法解剖问候为核心。** 可将第 8 课的问候音频和应答前移，语法解析留到所属与代词之后复现；重复应增加任务难度，而不只是再次看解释。
5. **第 7 课负荷过大。** 现在式人称前缀、将来时、三类否定和新动词一起出现，应拆为“我每天做什么”“明天的安排”“否定与纠正信息”。
6. **第 17 课的指示同位语与简单称呼出现偏晚。** “这本书”和“这是一本书”的差别适合紧接第 2 课；简单 `يَا أُسْتَاذُ` 可在课堂用语中先作为整体学会，呼格的分类规则再后置。
7. **第 16、19、21 课适合拆分专题。** 被动与状语、四类弱动词、三种修辞结构，分别需要独立目标和新语境练习。不能仅靠章节标题覆盖很多术语。
8. **没有必要让每个初学者走完所有高阶格位规则后，才有“学成”的节点。** 先提供一个可验收的基础路径，五名词、复杂条件句、派生体系放到明确标示的扩展区。

## 建议的双层课程路径

不建议立即全盘替换原语料或改变 lesson id。先以“学习目标”为索引重新编排已有材料，保留旧进度；验证基础路径有效之后再扩充内容。下表是设计建议，并非已实现的新课程。

| 路径阶段 | 复用内容 | 用户能完成的任务 | 需要补齐的验收 |
| --- | --- | --- | --- |
| A：第一次开口、认出常见字形 | 导引 1、导引 2、字母同形分组、第 8 课问候音频 | 问候、回应、说“我是学生”；认出本课词中的字母 | 无文字提示听辨；字形与读音匹配；录音后自听对照 |
| B：介绍身边的人和物 | 第 1、2 课，前移第 17 课指示同位语 | 说“这是一本书”“这本书很大”，区分阳性与阴性 | 新图片/新名词的句型迁移；不照抄原例句 |
| C：说位置、关系与所属 | 第 3、4、5 课，第 8 课对应部分 | 问在哪里，介绍家人，说谁的物品 | 问答配对、信息缺口任务、介词与后缀替换 |
| D：描述日常与计划 | 第 6、7 课拆分，第 13 课常用祈使 | 说自己昨天/今天/明天做什么；提出简单请求 | 新情境选时态，听短对话取信息，独立写/说 2–3 句 |
| E：数量与简单比较 | 第 9、11、12 课拆分，数字先学实用表达再讲全套规则 | 说数量、时间、比较选项 | 价格/时间/数量任务；性数配合的变式题 |
| F：基础综合里程碑 | A–E 累积复现 | 自我介绍、读短信息、理解短对话、表达需要 | 未见过的小任务；隔日/隔周复测；明确提示使用情况 |
| 扩展：语法专题 | 第 10、14–22 课与词法实验室 | 读懂更复杂书面结构，解释词形和句法 | 每专题单独目标、多种变式；不自动等同 CEFR 级别 |

第一周应尽量让用户每天看到“我现在能做什么”：能问候 → 能介绍身份 → 能辨认物品 → 能描述属性 → 能说位置 → 能表达所属 → 综合完成一次小对话。每天时长、词汇量和过关阈值需要用真实新手试学调整，不能靠固定日历保证掌握。

现代标准阿语、经典文本阅读和地区口语应在定位上说清楚。当前主线偏标准语的语法与书写。若面向旅行口语，需要选择地区并补充对应口语材料，不能把标准语的有声例句直接称为全面日常会话训练。

## 练习有效性：审计时发现的问题

| 优先级 | 可验证事实与位置 | 学习影响 | 建议 |
| --- | --- | --- | --- |
| P0 | `funGuide.ts` 的 50 个 `miniChecks.correctIndex` 全为 0；审计初始 `CourseMap.tsx:478` 按原顺序呈现 | 不理解内容也能每次选第一项全对 | 稳定随机排列选项；记录首次作答；首次错误后给解释，再以变式重测 |
| P0 | 初始 `SentencePractice.tsx:32` 默认展开 xray，答题中遍历全部正确 tokens 展示顺序和释义 | 练习变成照着答案拼，分数容易被误解为掌握 | 把指导练习与独立挑战分开；主动查看提示应被记录；作答后展示解析 |
| P0 | 初始 `CourseMap.tsx:170` 以 `score > 0` 计算完成；句子练习统计点击/按键正确率 | 低准确率、反复尝试也能被称为“通关” | 区分已练习、独立完成、延迟复测通过；不只换一个分数阈值 |

| P1 | `SentencePractice` 从 `ALL_SENTENCES` 全库抽干扰词 | 初学题可能混入高阶陌生词，且干扰项常无关 | 优先从已学词汇、同词性或同规则的易混形态抽取 |
| P1 | `VocabMiniGame` 称“听音辨词”，同时直接显示阿语和拉丁/中文谐音 | 能凭视觉答对，不能隔离验证听辨能力 | 增加真正隐藏文字的听辨模式，点击后再显示转写 |
| P1 | 键盘模式显示完整目标文字和下一键提示 | 更接近抄写与键位训练，不能直接证明语句生成能力 | 保留抄写训练，另做只给中文/情境的提取练习；学习分数与键盘熟练度分离 |
| P1 | `Letters.tsx:253` 和 `RootExplorer.tsx:394` 测验成绩仅存组件状态 | 返回后没有具体薄弱项记录，无法引导回顾 | 至少保存字母组/语法概念的首次正确率和待复习项 |
| P2 | `formatPronunciation` 将长短音及多个不同辅音映射到相同中文谐音 | 不能作为准确发音评价依据 | 中文谐音做可关闭的初期辅助，强调真人/经审校音频、音长和发音部位 |

上述行号是审计开始时的位置，同一轮实现可能改变行号。综合实现状态以代码 diff 和主报告为准。

一节课可先尝试如下结构：旧知识提取 2 题 → 一个可用表达 → 一个新规则 → 有提示变式 → 无提示新任务 → 告知下次复习对象。建议以 8–12 分钟作为试学原型目标，随后测量实际完成时间和中途退出位置，而不是对外承诺固定时长。

衡量成效至少区分：首次独立正确率、使用提示后的完成率、隔日/隔周保持率、未见过句子的迁移率。连续天数和打字速度可以支持习惯，但不能代替这些学习指标。

## 内容准确性与本轮修复

本轮只在 `grammar.ts` 做明确的小范围修正，没有重排课程数组，也没有改写整个语言题库。

| 位置（按 lesson id / 唯一文本可检索） | 原问题 | 本轮处理 |
| --- | --- | --- |
| `l0-script` 的 `وَرْدَةٌ` 例词解析 | 写成“仅 س 与 ة 相连”，词中没有 س | 已改为 و、ر、د 均不向左连，因此 ة 也独立；词内断开不是空格 |
| `l0-script` 的 `بَابٌ وَبَيْتٌ` tokens | 单独拆出 وَ，词块拼接会形成原句没有的空格 | 已合并为 وَبَيْتٌ，保持正确连词附着和整句对应 |
| `caseTypeForToken`（初始第 48 行） | 把解释中提到的其他成分也当成当前词格位：`كِتَابُ` 被判属格，`أَبْوَابُ` 被判宾格 | 只读当前 role，明确格位标签优先；说明文字不再覆盖词的角色 |
| `l1-hadha` | “阿语没有系动词”、词尾 ة “99%” 阴性 | 限定为现在时简单名词句通常不用系动词；去掉未经统计的 99% |
| `l4-idafa` | 将属格等同于一律读 -i/-in | 限定普通单数示例，说明双数、完整阳性复数、半变尾词等形式不同 |
| `l11-elative` | 半变尾词“禁绝齐齿符”，遗漏加冠词和作正次的条件 | 补上带 الـ 或作正次时属格恢复 -i 的条件 |
| `l19-weak-verbs` | 将首柔动词概括为只有 و 开头，并认为全部会脱落 و | 改为根首可为 و 或 ي；将脱落限定到本课常见例型，不推广给所有新动词 |
| `l22-derivations-mastery` | “看到任何阿语单词”都找三母词根，完成后“自如阅读” | 改为“许多派生实词”，明确需新语境、听力与无提示表达验证 |

剩余需要语言教师复核的具体项：

- `letters.ts:216` 将开口鼻音后不加 ا 的情况粗写为“除 ة / ء 外”。不能把所有 ء 结尾词都视作例外，例如 جزءًا 仍加 ا；应分别讲清 ة、ى、أ、اء 等拼写条件。巴勒斯坦理工大学的[书写与标点课程资料](https://www.ppu.edu/sites/default/files/attachments/%D9%82%D9%88%D8%A7%D8%B9%D8%AF%20%D8%A7%D9%84%D9%83%D8%AA%D8%A7%D8%A8%D8%A9%20%D9%88%D8%A7%D9%84%D8%AA%D8%B1%D9%82%D9%8A%D9%85.pdf)给出了“همزة على السطر”情况下 `جزءًا` 等例子。
- `grammar.ts` 的 `l2-nominal` 把“两个词同为泛指或定指”说成必然不是句子；宜明确“本课名词+形容词示例中”的适用范围，避免当成阿语所有名词句的通用判定器。
- `grammar.ts` 的 `l18-five-nouns` “只要接偏次”缺少单数、非缩小式等适用条件；`l17-nida-badal` 和专项测验对“单个呼语”也应补上专名/特指与非特指的区分。
- `funGuide.ts`、`morphology.ts` 有同一规则的重复解释。修正文案后需逐处同步审校，不能只修主讲义；尤其检查“永远”“所有”“铁律”有没有省略适用范围。
- 全库转写同时存在 `al-shamsu`、`ash-shamsu` 一类不同策略，应明确转写是表示字形还是实际连读读音；中文谐音不是音标，不能代替发音审校。
- 当前音频由外部 TTS 和系统语音提供，没有随课程附带经过教师审校的固定录音。`audio.ts` 的 `hasArabicVoice` 恒返回 true，无法据此认定每个设备都能真实发声。应对音频可用性、词尾停顿/连读和关键音位另做验收。

本轮新增 `tests/grammar-content.test.mjs`：核验全部 73 句 token 拼接与原句一致、显式格位与颜色分类一致，以及上面两个误分类例子的回归。运行：`node tests/grammar-content.test.mjs`，已通过。该检查只验证结构与分类，不代表全库阿语语言质量认证。

## 下一步执行次序

1. **先修测量失真和明确错误。** 随堂题选项位置、答案过早暴露、通关语义、格位色标、明显拼写说明。让“完成”反映真实练习过程。
2. **做一条可完整试学的第一周路径。** 只挑现有最基础材料，以可用表达组织。找 5–8 位目标新手观察试学，记录不理解的术语、第一次成功的时间和退出位置；该样本用于发现问题，不用于估计总体留存率。
3. **补题优先于补章节。** 先给前几课补无提示听辨、迁移句、间隔复习和阶段任务，再考虑扩充高阶语法。每个讲解点都必须能对应至少一种实际作答任务。
4. **统一内容审校规范。** 每条规则记录适用范围、例句、动符、转写、音频和易错点。分阶段进行阿语教师复核，避免一次批量生成大量未经审校的新题。
5. **再用行为与学习数据判断留存。** 观察用户是否因学会可用表达而回访；若只是打开页面或连续打字，不能推断学习成效。检验课程版本需要真实使用数据，当前仓库无法给出留存率结论。
