# Qalam 产品、课程与留存评估

日期：2026-11-16。目标人群：中文使用者中的零基础交流学习者、Tajweed（诵读规则）学习者、已有基础的语法学习者。

## 核心判断

项目已经有值得保留的内容资产：中文解释、阿语四形态和动符、词根家族、词法沙盒、逐词句法解析、键盘练习。当前短板不是功能数量，而是从“看懂讲解”走到“独立使用、隔天记住”的训练闭环。

当前课程的基础语法链大体合理，但后半部跨度过大、题量太少。若直接宣称完整覆盖三册并让用户独立掌握，依据不足。三类目标可以共用基础能力，但不能共用同一套毕业标准。当前没有真实用户行为或学习前后测数据，不能判断实际留存率，更不能声称本轮设计已经提高留存。

详细内容证据、计数、语言错误及逐课建议见 [curriculum-audit.md](./curriculum-audit.md)。该文记录审计时的问题；本轮修复状态以本文下表为准。

## 课程安排是否合理

实测：25 个单元（3 导引+22 正课）、61 个讲解点、73 道固定造句、50 道随堂题；20 个主题词库合计588项。第12–22课每课仅2道造句。

合理的骨架是第1–5课：指示与名词句 → 定指与形容词 → 介词 → 所属 → 代词。需要调整的是：

- 导引3在初学者识字尚不稳定时，先上词根、主动分词和时空名词，抽象概念过早。已将首页路线中的这一课后移到基础句型之后。
- 第7课同时教现在、将来和多种否定，宜拆为多个小单元，用同一套熟词逐步练习。
- 第16、19、21课分别并列多个困难主题，只有两道造句无法覆盖。需要拆课并补变式题。
- 问候应早学早用；后续重现时做更复杂的应答或阅读任务，而不是只重复讲语法。
- 指示同位语“这本书/这是一本书”适合靠近第2课；无需等到第17课才理解差别。
- 课程没有足够的真实听力、口语表达与陌生文本任务。照写、词块排序、语法选择题各有价值，但不能代替这些能力。

初级阶段应围绕可观察行为组织。CEFR 的入门描述以理解常见表达、提供简单个人信息等任务为中心，而非学过多少语法名词；这里借用设计原则，不声称产品已达到或认证 A1。[欧洲委员会描述库](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-descriptors-search)

## 三类用户如何共存

本轮已加入三个可保存的学习目标。日常交流与系统语法复用现有25单元，Tajweed另有规则讲解与概念自测；尚未开发三套完整独立课程。按用户最新要求，不建设经典原文精读、释义与注释。

| 路线 | 现阶段入口 | 建议接下来补什么 | 真正的阶段成果 |
| --- | --- | --- | --- |
| 日常交流入门 | 问候、拼读、物品、位置、所属、动作 | 自我介绍、购物、问路、时间等短对话；听辨与口头输出；明确标准语和地区口语边界 | 听懂一段新的短对话，完成一个简单问答任务 |
| Tajweed 入门 | 字音、鼻音、长音与常见诵读规则辨析 | 经核验的诵读录音、发音部位与特征训练、教师反馈和逐步跟读 | 识别规则，并经合格教师确认实际诵读能正确落实 |
| 系统语法巩固 | 名词句起步，允许按需选专题 | 简短诊断、同规则不同语境题、错误概念标签、综合阅读分析 | 对未见例句判断结构、说明理由，并完成同结构的表达 |

建议采用“共享基础 → 路线任务 → 可回到公共工具”的组织：共享字母与动符基础，交流路线以听说任务串联，Tajweed围绕诵读规则及其实际运用，语法路线以诊断和专题串联。Tajweed规则辨析不等于发音已合格；普通TTS不能作为诵读示范。范围与来源见 [tajweed-scope.md](./tajweed-scope.md)。

第一阶段不急于建设三套庞大内容库：各做一个小里程碑，邀请对应目标用户试学。路线是否合适，要看完成新任务和延迟复测的表现。

## 留存应该建立在什么上

目前用户缺少明确的回访理由：错题本只是累计列表，完成课程后没有到期复习、薄弱概念和下一次具体任务。首页堆叠模块也让第一次选择成本偏高。

建议最小闭环：

1. **第一次使用就完成一个小目标。** 比如说出身份、认出一个词、理解一个结构。先给成功体验，再展开全部工具。
2. **每课只有一个主要新目标。** 可试验8–12分钟的小课，但时长、词量要靠试学调整，不当作对外承诺。
3. **练习分三层。** 有提示学习 → 无提示完成新例句 → 过一段时间再回忆。错误给出原因，并让用户在新题里再应用。
4. **让明天的任务具体。** “回来复习今天的3个词”比单纯打卡更有学习意义。先做简单到期队列，再考虑复杂调度算法。
5. **允许轻量恢复。** 间隔几天回来时，从少量旧词和一句成功表达重新进入，不惩罚漏学。

间隔练习与提取练习有学习研究支持，但不意味着任何固定1/3/7天间隔都对所有人最优。可以把次日、数日后、下一周作为产品试验起点，根据错误和延迟表现调整。[Carpenter 等，2022，spacing and retrieval practice](https://doi.org/10.1038/s44159-022-00089-1)

不建议现在优先开发排行榜、积分商城、复杂成就或AI聊天。它们不能替代准确内容与学习闭环，也会增加运维和产品复杂度。

| 进度可信度 | 不再把任意非零分称为通关；独立成绩存入新版本进度，与旧提示成绩、可清空历史分离；80%仅作为下一课建议阈值，不宣称掌握 |
| 造句评估 | 默认不展示正确答案；查看答案/照写记为辅助练习；每句首次无误计分，切换模式不能清除错误；使用实际词数和实测会话经过时间 |
| 打字记录 | 全部跳过不再100%，不会出现从1970年开始累计的用时；Tab恢复焦点导航；结束与退出时清理延迟回调 |
| 统计展示 | 区分打字、无答案提示造句与辅助造句；速度图只显示打字；旧估算记录保留但不混入新汇总 |
| 随堂题 | 选项顺序随机化并保留首次选择，修复所有题答案原本都在第一项的问题 |
| 手机使用 | 屏幕键盘可点击输入字母、空格和动符，支持Shift、重打和朗读；窄屏重排键帽 |
| 路径连续性 | 课程生词练习或造句返回同一课与导学步骤；整页刷新恢复仍未实现 |
| 内容质量 | 修复连词词块、明确连写说明、格位误判及部分过度绝对的规则描述；未做全库语言审校 |
| 加载 | 使用React已有的懒加载按模块拆包，无新增依赖；最大JS文件从约662KB降为约292KB（未压缩构建文件大小，不等同首次加载总量） |

## 下一轮优先级

| 优先级 | 工作 | 完成标准 |
| --- | --- | --- |
| P0 | 阿语教师审校基础课、发音和重复规则文案 | 同一规则有适用范围；动符/转写/音频一致；已知问题关闭 |
| P1 | 前几课补真正无文字提示听辨、语境迁移与到期复习 | 用户不能只记原句顺序；隔天有明确复习内容；记录独立首次结果 |
| P1 | 三路线各一个小里程碑 | 交流任务、诵读规则与实际发音、语法迁移分别验收；不要共用打字速度作为成果 |
| P1 | 音频请求时序与失败提示 | 快速连点不会旧音覆盖新音；不可用时清楚提示；关键发音经人工审校 |
| P1 | 继续学习与数据可携带性 | 刷新后恢复到具体课/步骤；提供导出备份；之后再决定是否账号同步 |
| P2 | 小规模真实用户试学与指标 | 分路线观察首次成功时间、退出步骤、D1/D7学习回访和延迟保持率 |
| P2 | 再决定后端与商业化 | 只有当同步、多设备和真实用户量提出需求时再加，避免先建设复杂基础设施 |

不要用连续天数或累计词数代替学习效果。建议将“学习回访”定义为回来完成至少一次提取任务，另看完成者在24小时或一周后的无提示保持率。分母要明确：新用户、开始课程者、完成课程者不能混在一起。5–8人观察可发现可用性问题，不能用来估计稳定的总体留存率。

## 验证与边界

使用 `npm run build`、`npm run lint`、`npm test` 检查（会话统计、语法结构、学习路线、Tajweed内容四组回归）。构建与四组回归检查通过；lint没有错误，当前报告55条警告，主要来自现有练习组件的ref/纯度架构。

浏览器验证涵盖目标切换、课程入口、答案默认收起、触屏输入、返回课程和响应式布局。这里的验证不是全面可访问性审计、阿语教学认证或学习效果实验。

剩余限制：数据只在本机；会话经过时间并非扣除闲置的活跃时长；新独立分数仍来自固定题，且没有延迟复测，不能标为长期掌握；音频真实发声和发音质量没有完成跨设备验证。README同步补充当前范围与验证命令；本轮前已有、与本次无关的README编辑保留在工作区，不混入提交。
