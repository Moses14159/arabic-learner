# Tajweed 入门：范围、来源与验收

更新：2026-11-16。按用户要求，第二条路线只提供 Tajweed（诵读规则），不建设经典原文精读、释义或注释课程。

## 已提供的内容

`src/data/tajweed.ts` 包含6个中文规则单元、19道概念辨析题：

1. 短音、自然延长、静符/叠音符、Ghunnah。
2. 静音 نْ 与 tanwīn 的明读、并读、变读、隐读。
3. 静音 مْ 的唇隐读、唇并读、唇明读。
4. Qalqalah 的字母、触发状态与常见错误。
5. 基础停读词尾变化与 ج / صلى / قلى 标记。
6. 跨规则辨析与学习成果的边界。

课程以 Ḥafṣ ʿan ʿĀṣim（哈夫斯传自阿绥姆）的常见入门用法为范围。基础规则中有跨传承共享的部分；这里没有宣称涵盖全部传承差异或某一传承路线的全部细节。普通跨词并读题不处理特殊词位与断读。

示例是字母、音节或发音变化示意，**不是完整经句**；不包含自创经文、经文翻译或教义解释。`ةً → هْ` 表示停读时的发音变化，不是修改原书写。没有加入普通 TTS 示范，以免把一般语音合成误作可靠的 Tajweed 示范。

## 尚未覆盖

这是一套**规则识别入门**，不是完整诵读训练课程，尚未提供：

- 经教师审校且有使用许可的真人录音、听辨题和口型示范。
- 用户录音、发音对照、教师纠音或可靠的发音评分。
- 全部发音部位（makhārij）与字母性质（ṣifāt）的逐项训练。
- 完整的重轻读、ر 与特殊 ل、hamzat al-waṣl、各类延长音与路线差异。
- 全部停读/起读、特殊词形和特殊词位；自主给任意经句安排停顿。
- 经典内容精读、翻译、释义、注释。此项按用户要求不纳入当前路线。

自然延长与本课鼻音的“两拍”是相对诵读速度的时值，不是固定秒数。未把有路线差异的进阶延长拍数做成唯一答案题。后续要补声音材料时，先确定传承与路线，再请合格教师审校，不能直接接一般TTS替代。

## 验收方式

当前可验证：规则讲解可读、题目均有唯一的预设正确选项、反馈解释与讲解对应、成绩只代表本轮概念辨认。答案位置有分散，不全部放在第一项。

真实诵读的验收需要实际听辨、跟读和纠音，不能由本页分数推断。“已练习”与“诵读合格”必须分开。第一轮用户测试宜观察能否说出判断理由及隔日能否重新识别，再由教师对实际发音单独反馈。
