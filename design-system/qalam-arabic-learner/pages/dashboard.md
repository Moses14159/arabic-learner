# Learning dashboard override

Applies to the application shell and learning dashboard. The original MASTER remains available as historical guidance; the adult learning context requires a quieter visual language than its children's app palette and typography.

## Direction

Use warm paper surfaces, forest green actions and copper accents. The skill search `adult education minimal dashboard` matched Minimalism & Swiss Style; apply its spacing and hierarchy, adapted to Arabic and Chinese reading. Preserve the existing Arabic typeface and three user-selectable themes. Do not add display-font downloads or visual libraries.

## Tokens

- Light background: `#f7f7f2`; surface: white; inset: `#f2f3ed`.
- Primary text: `#203b31`; secondary text: `#637169`.
- Primary action: `#245a43` on white; copper accent: `#91672c`.
- Card radius: 16px; control radius: 10px; restrained shadows.
- Existing Outfit/system Chinese stack for UI; Noto Naskh Arabic/Geeza Pro for Arabic.

## Layout

Desktop uses a 212px persistent navigation rail and an uncluttered content area. A daily recommendation and weekly activity share the top row. Real learning metrics precede a course path, with review and reference tools in a secondary column. Course pages retain familiar learning controls.

Navigation becomes horizontal at 960px. The dashboard stacks at 640px. The primary action remains visible without competing with resource navigation. Theme and voice controls remain reachable at small sizes.

## Accessibility

Use semantic buttons and visible focus outlines. Most controls target 44px, keyboard keys preserve their established compact layout. Avoid horizontal document overflow; local navigation and data tables may scroll. Keep explanatory text separate from decorative Arabic artwork. Honor reduced motion. State indicators need text in addition to color. Scores and activity must come from actual persisted practice, with no invented streaks or progress.
